# Coursera Game Development Exercises

![Engine: Unity](https://img.shields.io/badge/Engine-Unity-555555)
![Language: C#](https://img.shields.io/badge/Language-C%23-512BD4)

Unity game-development course exercises, including Box Shooter, Roller Madness and Solar System projects.

## Getting started

- Clone the repository and add `Box Shooter`, `Roller Madness`, `Solar System` to Unity Hub as separate projects.

- Use the recorded Editor version as the starting point. For an upgrade, work on a separate branch and preserve all `.meta` files and serialized asset references.

- Open a project scene in the Editor and enter Play mode. Available scene examples: [Box Shooter/Assets/Scenes/Level1.unity](https://github.com/kleberandrade/coursera-gamedev/blob/master/Box%20Shooter/Assets/Scenes/Level1.unity), [Box Shooter/Assets/Scenes/Level2.unity](https://github.com/kleberandrade/coursera-gamedev/blob/master/Box%20Shooter/Assets/Scenes/Level2.unity), [Roller Madness/Assets/Scenes/Level1.unity](https://github.com/kleberandrade/coursera-gamedev/blob/master/Roller%20Madness/Assets/Scenes/Level1.unity), [Roller Madness/Assets/Scenes/Level2.unity](https://github.com/kleberandrade/coursera-gamedev/blob/master/Roller%20Madness/Assets/Scenes/Level2.unity), [Solar System/Assets/Scenes/Solar System.unity](https://github.com/kleberandrade/coursera-gamedev/blob/master/Solar%20System/Assets/Scenes/Solar%20System.unity).
